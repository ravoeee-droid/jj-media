# JJ-Media Website

Bearbeitbarer Stand des Vercel-Projekts `jj-clone`, rekonstruiert aus dem Production-Deployment vom 2. August 2026.

## Struktur

- Statische HTML-Seiten für Start, Über mich, Projekte, Leistungen und Kontakt
- Gemeinsames Styling in `styles.css`
- Interaktionen, Slider und ROI-Rechner in `app.js`
- Lokale Bilddateien unter `assets/`

## Lokal starten

Die Website benötigt keinen Build-Schritt. Sie kann mit jedem statischen Webserver gestartet werden.

## Vercel

Das Projekt kann direkt aus dem Repository importiert werden. `vercel.json` aktiviert die bereits im bestehenden Deployment verwendeten sauberen URLs ohne `.html`.
